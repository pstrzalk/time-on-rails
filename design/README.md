# Design Prototypes

This folder contains design prototypes and mockups for the Time on Rails application.

## Files

- `design-prototype-works.html` - Main works list page prototype with modern card-based design
- `design-prototype-new-work.html` - New work form prototype with enhanced UX

## Design System

### Colors
- Primary: Orange-500 (`#f97316`)
- Background: Gray-950 (`#0f172a`)
- Cards: Gray-900 (`#111827`)
- Text: White, Gray-200, Gray-400
- Borders: Gray-800, Gray-700

### Key Features
- Dark theme throughout
- Card-based layout for work sessions  
- Orange accent color for primary actions
- Running status with pulsing indicator
- Clean typography hierarchy
- Responsive design
- Consistent project badges
- Modern form design with sections

## Usage

These files serve as reference for maintaining design consistency across the application. They can be opened directly in a browser to preview the intended design.
